# omergulcicek.com

[Ömer Gülçiçek](https://omergulcicek.com) — Frontend Engineer kişisel sitesi.

Blog yazıları, projeler, deneyimler ve [ViraStack](https://virastack.com) ekosistemi burada. Detaya ve kaliteye önem veren bir frontend mühendisi olarak insanlara faydalı olmak, deneyimlerine değer katmak ve açık kaynak araçlar üretmek odağındayım.

## Tech stack

| Katman | Teknoloji |
| --- | --- |
| Framework | TanStack Start (Vite, SSR) |
| UI | React 19, Tailwind CSS, shadcn/ui |
| Dil | TypeScript |
| Veri | TanStack Query, Zod, Supabase |
| Animasyon | Motion |
| Deploy | Vercel |
