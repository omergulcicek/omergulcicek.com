Bir ödeme formunda kart numarası alanı tek başına yeterince dert: kaç hane alınacak, boşluklar nereye gelecek, numara geçerli mi? Geçerlilik için **Luhn algoritması** gerekiyor; **American Express** girince maske değişiyor, CVV dört haneye çıkıyor. Telefon, IBAN ve TCKN de kendi kurallarını getiriyor. Bunları her projede baştan yazmak hem vakit alıyor hem hata riskini artırıyor.

**ViraStack Mask** (`@virastack/mask`) bu alanlar için hazır ve test edilmiş maskeler sunuyor. React Hook Form ile çalışıyor: kullanıcı formatlı değeri görüyor, form ham değeri tutuyor.

## Ne Yapıyor?

- **React Hook Form için:** Input `(555) 123 45 67` gösteriyor, form `5551234567` tutuyor. `reset`, `setValue`, `watch` ve resolver'lar çalışmaya devam ediyor.
- **Tip güvenli:** Alan adları formunun tipine göre denetleniyor; yanlış bir ad derlemede hata veriyor.
- **Türkiye'ye hazır:** TCKN, VKN, IBAN, telefon, plaka ve kuruşlu TL; kartta Luhn, IBAN'da mod-97 kontrolü hazır.
- **Sunucuda aynı kurallar:** `@virastack/mask/server` aynı şemayı Server Action içinde doğruluyor.
- **Bağımlılık yok:** Hepsi birden 10 KB'ın altında.

## Dene

Kart numarası, son kullanma tarihi ve CVV birlikte çalışıyor. `34` ile başlayan bir Amex numarası yaz, maskenin ve CVV hanesinin değiştiğine bak. Her alanın altında formun tuttuğu ham değer ve ekranda görünen değer yan yana duruyor.

## Kullanım

Hook'a formu ve bir şema veriyorsun; her anahtar bir alan adı, değeri bir preset:

```tsx title="credit-card-form.tsx"
import { useViraMask } from "@virastack/mask"
import { useForm } from "react-hook-form"

type Card = { card: string; expiry: string; cvv: string }

export function CreditCardForm() {
  const form = useForm<Card>({ defaultValues: { card: "", expiry: "", cvv: "" } })

  const { card, expiry, cvv } = useViraMask(form, {
    card: "card",
    expiry: "expiry",
    cvv: { preset: "cvv", from: "card" }
  })

  return (
    <form onSubmit={form.handleSubmit(console.log)}>
      <input {...card} placeholder="0000 0000 0000 0000" />
      <input {...expiry} placeholder="AA/YY" />
      <input {...cvv} placeholder="123" />
    </form>
  )
}
```

`4111 1111 1111 1111` yazınca `form.watch("card")` boşluksuz `"4111111111111111"` döndürüyor. `from: "card"` CVV'yi kart alanına bağlıyor; Amex yazılınca CVV dört haneye çıkıyor.

Doğrulama hataları metin değil anahtar olarak dönüyor; metni ve çeviriyi sen yazıyorsun:

```ts
import { createMask } from "@virastack/mask/server"

createMask("card").validate("4111") // "card.incomplete"
createMask("card").validate("4111111111111112") // "card.invalid" (Luhn)
createMask("expiry").validate("0120") // "expiry.min", süresi dolmuş
createMask("tckn").validate("12345678901") // "tckn.invalid"
```

Telefon için `{ preset: "phone", country: "TR" }`, IBAN için `{ preset: "iban", country: "TR" }` ya da `"tckn"`, `"plate"`, `"currency"` gibi preset'leri aynı şemaya ekleyebilirsin.

Tüm preset'ler, sunucu doğrulaması, resolver kullanımı ve canlı örnekler [virastack.com/mask](https://virastack.com/mask) dokümanında, kaynak kod [github.com/virastack/form](https://github.com/virastack/form/tree/main/packages/mask) deposunda. Aynı formda parola ve adres için [ViraStack Password](/blog/virastack-password) ve [ViraStack Address](/blog/virastack-address) yazılarına bakabilirsin.
