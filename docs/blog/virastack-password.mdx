Parola alanındaki "göster / gizle" düğmesi birkaç satırlık bir `useState` gibi görünür. Ama işin içine girince liste uzar: ekran okuyucu düğmenin durumunu duymalı, form gönderilirken parola gizlenmeli ki parola yöneticisi doğru değeri kaydetsin, Caps Lock açıksa kullanıcı uyarılmalı. Üstüne parolanın gücünü ölçmek, iki alanın aynı olduğunu kontrol etmek ve aynı kuralları sunucuda tekrar çalıştırmak gelir. Her projede bunları baştan yazarsın ve bir yeri mutlaka unutursun.

**ViraStack Password** (`@virastack/password`) bu işi tek bir React hook'unda topluyor. Headless çalışıyor: input ve düğme için prop'ları veriyor, görünüm tamamen sende kalıyor. Bağımlılığı yok; hook yaklaşık 3 KB, güç motoru da yalnızca bir politika verdiğinde pakete giriyor.

## Ne Yapıyor?

- **Görünürlük:** Düğmeye `aria-pressed` ve `aria-controls` ekliyor, form gönderilince parolayı gizliyor, tıklamadan sonra odağı input'a geri veriyor, Caps Lock'u bildiriyor.
- **Güç:** NIST SP 800-63B'yi izliyor. Varsayılan politika 15–64 karakter istiyor ve büyük harf, sembol gibi kurallar koymuyor; seviye uzunlukla artıyor. Çok bilinen parolaları, tekrar eden karakterleri ve kişisel bilgileri yakalıyor.
- **Parola tekrarı:** `matchWith` ile ikinci alanın birinciyi tekrar edip etmediğine bakıyor.
- **Sunucu:** `@virastack/password/server` aynı politikayı Server Action içinde çalıştırıyor.
- **Sızmış parola:** İstersen `@virastack/password/pwned` parolayı Have I Been Pwned'de arıyor. Parolanın kendisini değil, SHA-1 özetinin ilk 5 karakterini gönderiyor.
- **Hata anahtarları:** Mesaj yerine `password.tooShort`, `password.mismatch` gibi anahtarlar dönüyor; metni ve çeviriyi sen yazıyorsun.

## Dene

Aşağıdaki alanlar varsayılan politikayla çalışıyor. Altındaki satırlar hook'un döndürdüğü değerler: seviye, hata anahtarları ve iki alanın eşleşip eşleşmediği.

## En basit hali

Sadece göster / gizle istiyorsan hook'u argümansız çağır:

```tsx title="password-field.tsx"
import { useViraPassword } from "@virastack/password"

export function PasswordField() {
  const { inputProps, btnProps } = useViraPassword()

  return (
    <div className="relative">
      <input {...inputProps} placeholder="Parolan" />
      <button {...btnProps} />
    </div>
  )
}
```

`btnProps` göz ikonlarıyla gelir. Metin istersen `icons` seçeneğini kullan:

```tsx
const { inputProps, btnProps } = useViraPassword({
  icons: { show: "Göster", hide: "Gizle" }
})
```

## Kayıt formu

Gerçek bir kayıt formunda politika, kişisel bilgi kontrolü ve parola tekrarı birlikte gerekir. Politikayı ayrı bir dosyada tanımla; aynı dosyayı sunucu da kullanacak:

```ts title="lib/password-policy.ts"
import { definePolicy } from "@virastack/password/strength"

export const policy = definePolicy() // NIST: 15–64 karakter
```

Sonra hook'u React Hook Form'a bağla. Her alan için bir giriş yazıyorsun; anahtar, alanın adı:

```tsx title="signup-form.tsx"
import { useForm } from "react-hook-form"
import { useViraPassword } from "@virastack/password"

import { policy } from "@/lib/password-policy"

export function SignupForm() {
  const form = useForm({ defaultValues: { email: "", password: "", confirm: "" } })

  const { password, confirm } = useViraPassword(form, {
    password: { policy, forbidden: ["email"] },
    confirm: { matchWith: "password" }
  })

  return (
    <form method="post" onSubmit={form.handleSubmit(console.log)}>
      <input type="email" autoComplete="username" {...form.register("email")} />

      <input {...password.inputProps} />
      <button {...password.btnProps} />
      <p {...password.strengthProps}>{password.strength?.level}</p>
      {password.capsLock && <p>Caps Lock açık</p>}

      <input {...confirm.inputProps} />
      <button {...confirm.btnProps} />
    </form>
  )
}
```

`inputProps` içinde `register()` zaten var, ayrıca çağırmana gerek yok. `forbidden: ["email"]` bir alan adı alıyor: parola, rakamları ve sembolleri çıkarınca e-postanın kullanıcı adına dönüşüyorsa (`ali` için `ali1990` gibi) reddediliyor. `strengthProps` bir `role="status"` bölgesi; seviye değişince ekran okuyucu bunu duyuruyor. Formdaki `method="post"` de önemli: sayfa yüklenmeden gönderilen bir form parolayı URL'ye yazmaz.

## Güç nasıl ölçülüyor?

Seviyeyi karakter türleri değil uzunluk belirliyor: minimum uzunlukta `fair`, 5 karakter fazlasında `good`, 10 karakter fazlasında `strong`. Kontroller parolanın tamamına bakıyor; rakamları, sembolleri ve tekrarları ayıklayıp öyle karşılaştırıyor. Varsayılan politikayla birkaç örnek:

```ts
import { definePolicy, evaluate } from "@virastack/password/strength"

const policy = definePolicy()

evaluate("Sakarya2026!", policy)
// { level: "weak", valid: false, issues: ["password.tooShort"] }

evaluate("123456789012345", policy)
// { level: "weak", valid: false, issues: ["password.repetitive"] }

evaluate("ali1990ali1990ali", policy, { forbidden: ["Ali Veli"] })
// { level: "weak", valid: false, issues: ["password.common", "password.containsPersonalInfo"] }

evaluate("kaliteli-sabah-kahvesi", policy)
// { level: "good", valid: true, issues: [] }

evaluate("sabah kahvesi ve deniz kenarı", policy)
// { level: "strong", valid: true, issues: [] }
```

"Sakarya2026!" büyük harf, rakam ve sembol içerdiği halde zayıf, çünkü 12 karakter. "sabah kahvesi ve deniz kenarı" ise sadece küçük harf ve boşluktan oluştuğu halde güçlü. NIST'in önerdiği de bu: uzun ve akılda kalan bir cümle, karmaşık ama kısa bir paroladan daha güvenli.

İkinci bir doğrulama adımın (MFA) varsa `definePolicy({ preset: "mfa" })` ile alt sınırı 8 karaktere indirebilirsin.

## Sunucuda aynı kurallar

İstemcideki kontrol atlanabilir. Bu yüzden aynı politikayı Server Action'da tekrar çalıştır:

```ts title="app/signup/actions.ts"
"use server"

import { validatePassword } from "@virastack/password/server"

import { policy } from "@/lib/password-policy"

export async function signup(formData: FormData) {
  const result = await validatePassword(formData.get("password"), policy, {
    forbidden: [formData.get("email")],
    confirm: formData.get("confirm"),
    pwned: { timeout: 3000 }
  })

  if (!result.valid) return { errors: result.issues }
  // result.password politikaya göre normalize edildi; hash'le ve kullanıcıyı oluştur
  return { ok: true }
}
```

İki parola farklıysa sonuç şöyle döner:

```ts
// { valid: false, issues: ["password.mismatch"], level: "good", … }
```

`pwned` seçeneği Have I Been Pwned'e soruyor; sızmış bir parola `password.pwned` alıyor. İstek zaman aşımına uğrarsa ya da başarısız olursa kayıt engellenmiyor. Bu kontrolü sunucuda yap: tarayıcıdan sorarsan Have I Been Pwned kullanıcının IP adresini görür.

Paketin ana girişi `"use client"` ile işaretli. Server Component ve Server Action içinde `/server` ya da `/strength` girişinden import et.

## Hata mesajları

Hook hata metni değil anahtar döndürüyor. Kendi metinlerini bir eşlemeyle yazarsın:

```ts
const messages: Record<string, string> = {
  "password.tooShort": "Parola en az 15 karakter olmalı",
  "password.common": "Bu parola çok yaygın",
  "password.containsPersonalInfo": "Parola kişisel bilgini içeriyor",
  "password.mismatch": "Parolalar aynı değil",
  "password.pwned": "Bu parola bir veri sızıntısında görülmüş"
}
```

## ViraStack Mask ile birlikte

[ViraStack Mask](/blog/virastack-mask) de değerleri React Hook Form'da tuttuğu için ikisi aynı `useForm`'u paylaşıyor. Maskeli bir alana göster / gizle düğmesi koymak istersen (örneğin bir PIN), ikisinin prop'larını aynı input'a yay:

```tsx
const { pin } = useViraMask(form, { pin: { mask: "999999" } })
const pinToggle = useViraPassword({ autoComplete: false })

<input {...pin} {...pinToggle.inputProps} />
<button {...pinToggle.btnProps} />
```
