Parola alanındaki "göster / gizle" düğmesi birkaç satırlık bir `useState` gibi görünür. Ama işin içine girince liste uzar: ekran okuyucu düğmenin durumunu duymalı, form gönderilince parola gizlenmeli ki parola yöneticisi doğru değeri kaydetsin, Caps Lock açıksa kullanıcı uyarılmalı. Üstüne parolanın gücünü ölçmek, tekrarını kontrol etmek ve aynı kuralları sunucuda çalıştırmak gelir.

**ViraStack Password** (`@virastack/password`) bunları tek bir headless React hook'unda topluyor: input ve düğme için prop'ları veriyor, görünüm sende kalıyor.

## Ne Yapıyor?

- **Erişilebilir görünürlük:** Düğmeye `aria-pressed` ekliyor, form gönderilince parolayı gizliyor, Caps Lock'u bildiriyor.
- **NIST tarzı güç:** Varsayılan politika 15–64 karakter istiyor ve büyük harf, sembol gibi kurallar koymuyor; seviye uzunlukla artıyor. Çok bilinen parolaları, tekrarları ve kişisel bilgileri yakalıyor.
- **Parola tekrarı:** `matchWith` ikinci alanın birinciyle aynı olup olmadığına bakıyor.
- **Sunucuda aynı kurallar:** `@virastack/password/server` aynı politikayı Server Action içinde çalıştırıyor; istersen Have I Been Pwned ile sızmış parolaları da kontrol ediyor.
- **Bağımlılık yok:** Hook yaklaşık 3 KB.

## Dene

Alanlar varsayılan politikayla çalışıyor. Altındaki satırlar hook'un döndürdüğü seviye, hata anahtarları ve iki alanın eşleşip eşleşmediği.

## Kullanım

Sadece göster / gizle için hook'u argümansız çağır:

```tsx title="password-field.tsx"
import { useViraPassword } from "@virastack/password"

export function PasswordField() {
  const { inputProps, btnProps } = useViraPassword()

  return (
    <div className="relative">
      <input {...inputProps} placeholder="Parolan" />
      <button {...btnProps} />
    </div>
  )
}
```

Kayıt formunda React Hook Form'a bağla; her giriş bir alan adı:

```tsx title="signup-form.tsx"
import { definePolicy } from "@virastack/password/strength"

const policy = definePolicy() // NIST: 15–64 karakter

const { password, confirm } = useViraPassword(form, {
  password: { policy, forbidden: ["email"] },
  confirm: { matchWith: "password" }
})

<input {...password.inputProps} />
<p {...password.strengthProps}>{password.strength?.level}</p>
<input {...confirm.inputProps} />
```

## Güç nasıl ölçülüyor?

Seviyeyi karakter türleri değil uzunluk belirliyor. Varsayılan politikayla gerçek sonuçlar:

```ts
import { definePolicy, evaluate } from "@virastack/password/strength"

const policy = definePolicy()

evaluate("Sakarya2026!", policy)
// { level: "weak", valid: false, issues: ["password.tooShort"] }

evaluate("ali1990ali1990ali", policy, { forbidden: ["Ali Veli"] })
// { level: "weak", valid: false, issues: ["password.common", "password.containsPersonalInfo"] }

evaluate("sabah kahvesi ve deniz kenarı", policy)
// { level: "strong", valid: true, issues: [] }
```

"Sakarya2026!" büyük harf, rakam ve sembol içerdiği halde 12 karakter olduğu için zayıf; küçük harfli uzun bir cümle ise güçlü. NIST'in önerdiği de bu: uzun ve akılda kalan bir parola, kısa ve karmaşık olandan daha güvenli.
